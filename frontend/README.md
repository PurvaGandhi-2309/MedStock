MedStock – Smart Medicine Inventory Management

MedStock is a medicine inventory management application designed to help pharmacies manage medicines, monitor batch-level stock, track expiry dates, and maintain stock transaction history.

Features

- Dashboard:View inventory statistics and important stock alerts.
- Medicine Management:Add, view, update, and search medicines.
- Batch Management:Manage medicine batches, quantities, and expiry dates.
- Stock Management:Record stock movements and monitor inventory levels.
- Transaction History:Track stock IN and OUT transactions.
- Alerts:Identify low-stock medicines, expired batches, and medicines expiring soon.
- Reorder Recommendations: Help identify medicines that may need restocking.
- AI Insights:Generate inventory insights using AI integration.

## Technology Stack

- React
- Vite
- JavaScript
- Node.js and Express.js
- MongoDB
- Gemini API
- Recharts

 1. Install Dependencies

```bash
npm install
```
 2. Start the Development Server

```bash
npm run dev
```
 3. Open the Application

Open the local URL displayed in your terminal.
